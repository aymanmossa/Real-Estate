# Real Estate Website

This project is a real estate website built using HTML, CSS, and JavaScript. It showcases various properties with images and details.

## Features

- Property listings with images
- Responsive design
- Interactive elements

## Getting Started

To view the website, open `index.html` in a web browser.

## Project Structure

- `index.html`: Main HTML file
- `style.css`: Stylesheet
- `script.js`: JavaScript for interactivity
- `img/`: Directory containing property images
- `ScreenShots/`: Screenshots of the application
